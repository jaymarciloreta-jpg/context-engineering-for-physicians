# Physician Starter Vault

A ready-made Obsidian vault for working with Claude. From the Context Engineering for Physicians wiki:
https://jaymarciloreta-jpg.github.io/context-engineering-for-physicians/

## Use it in four steps
1. Unzip this folder somewhere you can find it (for example, Documents).
2. In Obsidian: Open folder as vault, and choose this folder.
3. Open CLAUDE.md and fill in the brackets. Keep it under one page.
4. In the Claude desktop app, start a task on this folder and say:
   "Read CLAUDE.md and the README, then help me set up my first real project."

## What is inside
- CLAUDE.md: your about-me file. Claude reads it automatically.
- 00 Inbox to 04 Archive: the PARA folders.
- Daily: one note per day.
- Templates: project brief, area note, daily note.
- skills: ready-made recipes. Say "run the recipe in skills/weekly-plan.md".
- 01 Projects/Example Project: a sample project brief to copy.

Never put identifiable patient information in this vault.
