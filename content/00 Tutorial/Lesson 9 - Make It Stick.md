**Goal:** turn the setup into a habit. **Time:** 5 minutes.

You now have all Four C's: a context file, a connection, recipes, and a schedule. What makes it compound is three small habits.

## The three habits

1. **The project loop.** Start each work session with "read the brief, where are we?" End it with "update Status and Next."
2. **Fix the cause.** When Claude gets something wrong twice, add a rule to `CLAUDE.md` or the recipe instead of correcting it again. See [[When AI Gets It Wrong]].
3. **Tidy monthly.** Run the vault tidy-up recipe from the [[Recipe Library]] at the end of each month.

## Your first week

| Day | Do this |
|---|---|
| 1 | Read your morning brief. Use the project loop once. |
| 2 | Add one rule to `CLAUDE.md` from something you re-explained. |
| 3 | Run one recipe on real work. |
| 4 | Process one meeting note into action items. |
| 5 | Turn a task you did by hand this week into a new recipe. |
| 7 | Read your weekly digest (or run the weekly plan recipe). |

## Do it with Claude

```text
Read my vault. Summarize what I have set up so far, then suggest the one
next recipe or connection that would save me the most time, based on what
you see in my projects and daily notes.
```
