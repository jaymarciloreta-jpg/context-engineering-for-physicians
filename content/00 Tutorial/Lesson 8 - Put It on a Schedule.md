**Goal:** one task that runs on its own and leaves you a note to read. **Time:** 10 minutes.

## Steps

1. **Pick one:** a weekday **morning brief** or a Sunday **weekly digest**. Both are on [[Scheduled Recipes]].
2. **Save it** in `skills/`.
3. **Run it once by hand** and adjust until you like the result.
4. **Schedule it** at the slowest useful pace.

## Do it with Claude

```text
Write a morning brief recipe in skills/morning-brief.md: today's calendar
with what to prep, any project deadlines in the next 7 days, under 250 words,
saved to Daily. Run it once now so I can see it.
```

When it looks right:

```text
Run the recipe in skills/morning-brief.md every weekday at 6:00 am.
```

> [!note] Keep scheduled tasks to drafts and reports
> A scheduled task should write you a note, not send emails or delete files. Watch it for a few weeks before giving it any more independence. Tasks that read your vault need the Claude desktop app open.

## Checkpoint

- [ ] One scheduled task set up.
- [ ] You read its first result.
